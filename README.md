## Overview

Aura Tech Stores is a Spring Boot web application created as an electronics-store project with separate Cairo and Alexandria branch context.

This repository represents an earlier stage of my Java/Spring development work and is kept as part of my engineering portfolio progression.

## Run Locally

1. Open the project in IntelliJ IDEA.
2. Run `Application.java`.
3. Open:

```text
http://localhost:8080
```
